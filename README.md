# Проба сканера

Тимчасова статична сторінка для перевірки на телефонах:

- чи камера в браузері читає штрихкоди, багато підряд;
- чи телефон лишається «запамʼятаним» між відкриттями;
- скільки важить фото після стискання.

Сторінка нічого нікуди не надсилає: немає сервера, аналітики й сторонніх адрес. Усе, що вона памʼятає, лежить лише на телефоні. Звіт людина копіює кнопкою й надсилає сама.

Самоперевірка читача без камери — `selftest.html`.

Читач кодів — zxing-wasm 3.1.6 (MIT), зібраний із zxing-cpp (Apache-2.0). Файли й ліцензії — у `vendor/zxing-wasm`.
